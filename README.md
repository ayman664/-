# موقع الشاعرة والفنانة المسرحية فضيلة زيدان ناجي العامري

موقع سيرة ذاتية عربي مبني باستخدام Python وFlask وHTML وCSS، ويحفظ البيانات في قاعدة SQLite محلية.

## التشغيل

```powershell
$env:ADMIN_PASSWORD = "اختر-كلمة-مرور-قوية"
uv run --with Flask -m flask --app app run --port 5000
```

ثم افتح <http://127.0.0.1:5000> في المتصفح. ينشئ التطبيق قاعدة البيانات تلقائيًا في مجلد `data` عند أول تشغيل.

رابط دخول الإدارة هو <http://127.0.0.1:5000/admin/login>. لا يظهر زر **إضافة قصيدة** ولا زر تحرير السيرة للزوار؛ يظهران بعد تسجيل الدخول. إذا لم يُضبط `ADMIN_PASSWORD`، يُعطّل تسجيل الدخول وتظهر رسالة إعداد بدلًا من ذلك.

في الاستضافة، اضبط `ADMIN_PASSWORD` و`SECRET_KEY` كمتغيري بيئة سريين، ولا تضعهما في ملفات المشروع. عند النشر عبر HTTPS، اضبط أيضًا `SESSION_COOKIE_SECURE=true`.

يحتوي الموقع على:
- صفحة السيرة الذاتية مع بيانات الفنانة وعمرها
- قسم المسيرة الفنية مع أقسامها الزمنية
- قسم قصائد الشاعرة مع تصفية تفاعلية ونصّ مختار في الجهة اليمنى
- إضافة القصائد وتحرير السيرة بعد تسجيل دخول الإدارة
- عرض القصائد بأسطر ومقاطع واضحة، وحصر تصنيفاتها في **شعر** و**أبوذية**
- معرض تفاعلي للصور المسرحية مع تحريك بصري خفيف يحترم إعداد تقليل الحركة

تُعرض سنة الميلاد 1956م، ويُحسب العمر تلقائيًا عند تسجيل تاريخ ميلاد كامل.

صور الأرشيف داخل `static/gallery` نسخ من الصور المرفوعة؛ لم نغيّر ملفات المصدر. التحسين اللوني والتحريك يطبّقان عند العرض فقط، والصور محفوظة كاملة دون قص في المعرض.

يتقدم معرض الصور تلقائيًا كل خمس ثوانٍ، ويتوقف مؤقتًا عند التركيز عليه أو مرور المؤشر فوقه، كما يُعطّل عند تفعيل إعداد تقليل الحركة. حُذفت القصائد التجريبية من قاعدة البيانات ولن تُضاف مجددًا تلقائيًا؛ أضيفي القصائد الجديدة من حساب الإدارة.

## النشر على Render

يتضمن المشروع ملف `render.yaml` لإنشاء تطبيق Flask مجاني مع Gunicorn. نظام الملفات في الخطة المجانية مؤقت؛ القصائد التي تضيفينها محفوظة محليًا في SQLite على الخادم، وقد تُفقد عند إعادة تشغيل الخدمة أو نومها أو إعادة نشرها. كما تنام الخدمة المجانية بعد 15 دقيقة بلا زيارات، وقد يستغرق فتحها مجددًا نحو دقيقة. لا تستخدمي هذا الخيار لأرشيف دائم أو إنتاج حساس.

1. ارفعي مجلد المشروع إلى مستودع GitHub، مع تضمين `render.yaml` و`requirements.txt` وملفات `templates` و`static`. لا ترفعي ملفات `.env` أو قاعدة `data/biography.sqlite3`.
2. في Render اختاري **New → Blueprint**, اربطي مستودع GitHub، ثم وافقي على إعدادات `render.yaml`.
3. أدخلي `ADMIN_PASSWORD` كسرّ في Render. لا تضعيه في `render.yaml` أو GitHub. سيولّد Render قيمة `SECRET_KEY` تلقائيًا.
4. بعد اكتمال النشر، استخدمي رابط `onrender.com` الذي يظهر في لوحة Render. دخول الإدارة يكون بإضافة `/admin/login` إلى الرابط.

المصدر منشور في مستودع GitHub العام: <https://github.com/ayman664/->. رابط التطبيق العام سيظهر بعد إنشاء الخدمة واكتمال أول عملية نشر على Render. ملف قاعدة البيانات المحلية مستثنى من Git، وستبدأ قاعدة الإنتاج فارغة من القصائد لإضافتها من الإدارة.

## الظهور في محركات البحث

تتضمن الصفحة عنوانًا ووصفًا مناسبين للبحث عن «فضيلة العامري» و«فضيلة زيدان ناجي العامري»، وبيانات منظّمة عن الفنانة، ورابطًا أساسيًا للصفحة، وملفي `robots.txt` و`sitemap.xml`. تستخدم الاستضافة عنوان Render تلقائيًا؛ وعند ربط نطاق مخصص، اضبط متغير البيئة `SITE_URL` على العنوان الأساسي الكامل مثل `https://example.com`.

بعد نشر الموقع على رابط عام:

1. أضف نطاق الموقع في [Google Search Console](https://search.google.com/search-console/) وأكّد ملكيته بالطريقة التي توفرها Google.
2. أرسل خريطة الموقع `https://رابط-موقعك/sitemap.xml` من صفحة **خرائط المواقع**.
3. استخدم **فحص عنوان URL** لطلب فهرسة الصفحة الرئيسية.

الفهرسة والترتيب من قرارات محركات البحث، وقد يستغرق ظهوره أيامًا أو أسابيع ولا يمكن ضمان نتيجة أو ترتيب محدد. إعداد ملفات المشروع لا ينشر الموقع أو يؤكد ملكية نطاق Search Console تلقائيًا؛ يلزم إتمام ربط المستودع بحساب Render والتحقق من ملكية الموقع لدى Google.
