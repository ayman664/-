# موقع الشاعرة والفنانة المسرحية فضيلة زيدان ناجي العامري

موقع سيرة ذاتية عربي مبني باستخدام Python وFlask وHTML وCSS، ويحفظ البيانات في قاعدة SQLite محلية.

## التشغيل

```powershell
$env:ADMIN_PASSWORD = "اختر-كلمة-مرور-قوية"
uv run --with Flask -m flask --app app run --port 5000
```

ثم افتح <http://127.0.0.1:5000> في المتصفح. ينشئ التطبيق قاعدة البيانات تلقائيًا في مجلد `data` عند أول تشغيل.

رابط دخول الإدارة هو <http://127.0.0.1:5000/admin/login>. لا يظهر زر **إضافة قصيدة** ولا زر تحرير السيرة للزوار؛ يظهران بعد تسجيل الدخول. إذا لم يُضبط `ADMIN_PASSWORD`، يُعطّل تسجيل الدخول وتظهر رسالة إعداد بدلًا من ذلك.

في الاستضافة، اضبط `ADMIN_PASSWORD` و`SECRET_KEY` كمتغيري بيئة سريين، ولا تضعهما في ملفات المشروع. عند النشر عبر HTTPS، اضبط أيضًا `SESSION_COOKIE_SECURE=true`.

يحتوي الموقع على:
- صفحة السيرة الذاتية مع بيانات الفنانة وعمرها
- قسم المسيرة الفنية مع أقسامها الزمنية
- قسم قصائد الشاعرة مع تصفية تفاعلية ونصّ مختار في الجهة اليمنى
- إضافة القصائد وتحرير السيرة بعد تسجيل دخول الإدارة
- عرض القصائد بأسطر ومقاطع واضحة، وحصر تصنيفاتها في **شعر** و**أبوذية**
- معرض تفاعلي للصور المسرحية مع تحريك بصري خفيف يحترم إعداد تقليل الحركة

تُعرض سنة الميلاد 1956م، ويُحسب العمر تلقائيًا عند تسجيل تاريخ ميلاد كامل.

صور الأرشيف داخل `static/gallery` نسخ من الصور المرفوعة؛ لم نغيّر ملفات المصدر. التحسين اللوني والتحريك يطبّقان عند العرض فقط، والصور محفوظة كاملة دون قص في المعرض.

يتقدم معرض الصور تلقائيًا كل خمس ثوانٍ، ويتوقف مؤقتًا عند التركيز عليه أو مرور المؤشر فوقه، كما يُعطّل عند تفعيل إعداد تقليل الحركة. حُذفت القصائد التجريبية من قاعدة البيانات ولن تُضاف مجددًا تلقائيًا؛ أضيفي القصائد الجديدة من حساب الإدارة.

## النشر المجاني على GitHub Pages

ينشر GitHub Actions نسخة ثابتة من الموقع مجانًا على <https://ayman664.github.io/-> عند كل تحديث لفرع `main`. لا يحتاج النشر إلى Render أو بطاقة دفع. يحتفظ Flask بعمله عند التشغيل المحلي، أما النسخة المنشورة فهي للقراءة فقط: لا يمكن للزوار أو الإدارة إضافة القصائد أو تحرير السيرة فيها، لأن GitHub Pages يستضيف ملفات ثابتة ولا يشغّل خادم Flask.

ملف `.github/workflows/pages.yml` يبني الصفحة وملفات الصور وملفي الروبوتات وخريطة الموقع ثم ينشرها. يستخدم `scripts/build_static.py` عنوان المشروع الفرعي الصحيح على GitHub Pages. لا ترفع ملفات `.env` أو قاعدة `data/biography.sqlite3`.

يتطلب تفعيل GitHub Pages على المستودع أول مرة صلاحية مالك الحساب؛ سير العمل يحاول إعداد Pages تلقائيًا. بعد اكتمال أول تشغيل ناجح، سيكون الموقع متاحًا على <https://ayman664.github.io/->.

## الظهور في محركات البحث

تتضمن الصفحة عنوانًا ووصفًا مناسبين للبحث عن «فضيلة العامري» و«فضيلة زيدان ناجي العامري»، وبيانات منظّمة عن الفنانة، ورابطًا أساسيًا للصفحة، وملفي `robots.txt` و`sitemap.xml`.

بعد نشر الموقع على رابط عام:

1. أضف `https://ayman664.github.io/-/` في [Google Search Console](https://search.google.com/search-console/) وأكّد ملكيته بالطريقة التي توفرها Google.
2. أرسل `https://ayman664.github.io/-/sitemap.xml` من صفحة **خرائط المواقع**.
3. استخدم **فحص عنوان URL** لطلب فهرسة الصفحة الرئيسية.

الفهرسة والترتيب من قرارات محركات البحث، وقد يستغرق ظهوره أيامًا أو أسابيع ولا يمكن ضمان نتيجة أو ترتيب محدد. إعدادات Google Search Console تتطلب تسجيل دخول مالك الموقع، لذلك يجب إكمالها من حساب Google الخاص به.
